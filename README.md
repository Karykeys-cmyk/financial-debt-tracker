# 💰 Финансовый учёт

Веб-приложение для учёта дебиторской задолженности.

**[👉 ОТКРЫТЬ ПРИЛОЖЕНИЕ](https://karykeys-cmyk.github.io/financial-debt-tracker)**

---

## 📋 Описание

Приложение позволяет вести учёт финансовых взаиморасчётов с контрагентами:

- 🏠 Аренда помещения (коммуналка, аренда ДТФ, счета)
- 💰 Деньги в долг (с автоматическим расчётом процентов)

Все данные сохраняются в **localStorage** браузера.

---

## 👥 Контрагенты

| Контрагент | Вкладки |
|------------|---------|
| **Даня** | Аренда помещения (Коммуналка, Аренда ДТФ, Счета) + Деньги в долг |
| **Максюшка** | Аренда помещения (Коммуналка, Счета) + Деньги в долг |
| **Новые** | Только Деньги в долг |

---

## 🚀 Возможности

- ➕ Создание контрагентов
- 📊 Автоматический расчёт: Дебет, Кредит, Сальдо
- 📝 Добавление, редактирование и удаление записей
- 📅 Сортировка по дате (новые сверху)
- 💰 Авторасчёт прибыли по займам: `(Сумма × % / 100) × (Дни / 365)`
- 💾 Автосохранение в localStorage
- 📱 Адаптивный дизайн
- 🎨 Тёмно-синяя тема с голубыми акцентами
