# Финансовый учёт

Одностраничное приложение для учёта дебиторской задолженности. Данные хранятся в браузере. Интерфейс на русском языке.

## Открыть приложение

[https://karykeys-cmyk.github.io/financial-debt-tracker/](https://karykeys-cmyk.github.io/financial-debt-tracker/)

Иконку на экран «Домой» достаточно поставить один раз. Обновления подтягиваются сами: открыли приложение — оно сверяет версию с сайтом и перезагружается, если вышла новая. Удалять иконку и ставить заново не нужно (это только если хотите сменить картинку на иконке).

Один раз в репозитории на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save**. После этого ссылка выше открывает приложение.

Репозиторий: [github.com/Karykeys-cmyk/financial-debt-tracker](https://github.com/Karykeys-cmyk/financial-debt-tracker)

## На экран «Домой»

Приложение можно поставить как иконку на телефон — откроется без адресной строки, как обычное приложение. Для этого нужны манифест, иконки и HTTPS (GitHub Pages это уже даёт).

**iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран „Домой“» → Добавить. Название на иконке: «База». Дальше обновления приходят сами, иконку не трогайте.

**Android (Chrome):** откройте ссылку → меню ⋮ → «Добавить на главный экран» или «Установить приложение». Обновления тоже подтягиваются при открытии.

## Личные кабинеты

Вход администратора: логин `admin`, пароль `baseadmin`. Кабинет запоминается на устройстве и не сбрасывается при закрытии вкладки — выйти можно кнопкой «Выйти».

На главной аналитика: за всё время или за месяц. Прибыль за месяц считает только дни внутри этого месяца и не крутит проценты после даты возврата. Если выбран ещё не наступивший месяц, вместо прибыли показывается **планируемый доход** — сумма, которая уже посчитана на этот будущий месяц.

Администратор через «Личные кабинеты» смотрит список кабинетов. Новая запись создаётся кнопкой «Создать кабинет» внутри этого окна; после сохранения форма закрывается и снова виден список.

- **Нахлебничек ♥** — своя книга учёта с нуля. Можно добавлять арендаторов денег только с графой «Деньги в долг» (без аренды, ДТФ и счетов).
- **Арендатор денег** — тоже полноценный кабинет. Выбирается из ваших контрагентов: у него заранее есть карточка долга на имя **Кариша** с теми же цифрами, что вы видите в его карточке. Если возврат просрочен, карточка «Кариша» и сам долг светятся красным так же, как просроченный должник на вашей главной. Дальше он пользуется интерфейсом как нахлебничек.

## Контрагенты

- **Даня** — вкладки «Аренда помещения» (Коммуналка, Аренда), «Аренда ДТФ», «Счета», «Деньги в долг», «Выплачено» и временная «Требует сортировки»
- **Максюшка** — вкладки «Аренда помещения» (Коммуналка, Аренда), «Счета», «Деньги в долг», «Выплачено» и «Требует сортировки». Без «Аренда ДТФ»
- Новые контрагенты создаются с вкладками «Деньги в долг», «Выплачено» и «Требует сортировки»

## Возможности

- Сверху светло-серая полоса с логотипом «База Баляевой». Справа круглая кнопка синхронизации со стрелками: крутится, пока идёт обмен, и становится зелёной, когда данные синхронизированы. Долгое нажатие открывает настройки синхронизации
- На главной: сумма долгов нам, прибыль по процентам, сумма наших долгов и потери на процентах
- Карточку контрагента можно удалить с главной и из профиля
- Выдали в долг — со сроком возврата; взяли в долг — срок можно не указывать
- Карточки Дани: аренда вместе с коммуналкой, отдельно Аренда ДТФ и «Всего отдано»
- Итоги в карточке: дебет, кредит, сальдо, прибыль за всё время (зелёный сальдо — нам должны, красный — должны мы)
- Аналитика за весь период, за год или за месяц
- Над списком записей у любого контрагента и любой вкладки: добавить запись, поиск и сворачивание. Поиск смотрит все записи контрагента, не только текущую вкладку
- Выплата не отдельная запись: она привязана к долгу. В рабочих вкладках остаются только открытые долги с остатком
- Погашенные записи уходят во вкладку «Выплачено». Нажмите на долг — сверху сразу видно, какая выплата его закрыла: дата, сумма и способ.
- Внести оплату можно из самой записи («Оплата» или внутри долга) либо через «Добавить запись» → тип «Возврат» с выбором долга. Если долг с процентами, в сумму выплаты сразу подставляется тело плюс проценты: вернули 550 по займу 500 — долг закрывается, в «Требует сортировки» ничего не уходит. Туда попадает только то, что больше тела и процентов. На главной «Сумма долгов» считает тело займа, без планируемых процентов.
- Временная вкладка «Требует сортировки»: выплаты без выбранного долга. Карандаш меняет сумму, дату и способ оплаты, «К долгу» привязывает выплату. Когда разнесёте всё — вкладку уберём
- Счёт с тем же номером, той же датой и тем же юрлицом повторно не создаётся — откройте уже существующую запись
- При добавлении и правке счёта нужно выбрать юрлицо: ООО «МАКСИЛАЙТ» или ИП Баляева К.М.
- Если выплата больше остатка по выбранному долгу, долг закрывается на эту сумму, а разница появляется во вкладке «Требует сортировки» — её можно привязать к другому долгу
- Если выплату сняли с долга, она уходит во вкладку «Требует сортировки», а долг снова открывается. Синхронизация больше не приклеивает эту выплату обратно. Удалённые долги и выплаты лежат в кнопке «Удалённые» — оттуда можно вернуть или стереть навсегда. Если удалить сам долг, выплаты сначала уходят в «Требует сортировки».
- Способ оплаты у выплаты: наличные, перевод, безналичный расчёт, услугами, товарами, взаимозачёт
- Выдача в долг с обязательным сроком возврата; если к этой дате нет полного погашения, карточка должника и сам долг светятся красным — в том числе в личном кабинете арендатора денег
- Необязательный комментарий у любой записи
- Фильтр таблицы по способу оплаты
- Авторасчёт прибыли по займам
- Автосохранение на устройстве и синхронизация через Supabase между устройствами

## Синхронизация между устройствами

Проект: [https://sqsnhapkgtdjjkiexfrn.supabase.co](https://sqsnhapkgtdjjkiexfrn.supabase.co)

Клиент ходит в Supabase напрямую (без отдельной библиотеки). После каждой записи приложение сначала забирает облако, сливает с тем, что на устройстве, и сразу отправляет обратно — так телефон не затирает компьютер и наоборот. Если вкладку свернули, синхронизация всё равно дожимается.

Один раз создайте таблицу — в SQL Editor вставьте скрипт из «Настройки синхронизации» или выполните:

```bash
supabase login
supabase init
supabase link --project-ref sqsnhapkgtdjjkiexfrn
supabase db push
```

После этого записи с телефона и компьютера сохраняются в облаке и подтягиваются на других устройствах.
