# Финансовый учёт

Веб-приложение для учёта дебиторской задолженности: аренда помещения и деньги в долг. Все данные хранятся в `localStorage` браузера. Интерфейс полностью на русском языке.

## Контрагенты

- **Даня** — вкладки «Аренда помещения» (Коммуналка, Аренда ДТФ, Счета) и «Деньги в долг»
- **Максюшка** — вкладки «Аренда помещения» (Коммуналка, Счета) и «Деньги в долг». Без «Аренда ДТФ»
- Новые контрагенты создаются только с вкладкой «Деньги в долг»

## Возможности

- Карточки контрагентов на главном экране
- Итоги: дебет, кредит, сальдо
- Добавление, редактирование и удаление записей
- Авторасчёт прибыли по займам: `(сумма × % / 100) × (дни / 365)`
- Автосохранение в `localStorage`

## Запуск

Нужны Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:43127](http://127.0.0.1:43127).

Сборка для публикации:

```bash
npm run build
npm run preview
```

Исходный код — один файл `index.html` со встроенными CSS и JavaScript, без внешних библиотек.
