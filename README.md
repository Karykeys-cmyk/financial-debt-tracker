# Финансовый учёт

Одностраничное приложение для учёта дебиторской задолженности. Данные хранятся в браузере. Интерфейс на русском языке.

## Открыть приложение

[https://karykeys-cmyk.github.io/financial-debt-tracker/?v=43](https://karykeys-cmyk.github.io/financial-debt-tracker/?v=43)

Если с телефона видите старые данные, откройте именно эту ссылку в Safari или Chrome, не с иконки на экране. Новый адрес обходит кэш.

Иконка на экран «Домой» — логотип «База Баляевой». На iPhone: откройте ссылку в Safari → Поделиться → На экран «Домой». Если иконка уже стояла, удалите старую и добавьте заново, иначе телефон может держать прежнюю картинку.

Один раз в репозитории на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save**. После этого ссылка выше открывает приложение.

Репозиторий: [github.com/Karykeys-cmyk/financial-debt-tracker](https://github.com/Karykeys-cmyk/financial-debt-tracker)

## На экран «Домой»

Приложение можно поставить как иконку на телефон — откроется без адресной строки, как обычное приложение. Для этого нужны манифест, иконки и HTTPS (GitHub Pages это уже даёт).

**iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран „Домой“» → Добавить. Название на иконке: «База». Если иконка уже была — удалите и добавьте снова.

**Android (Chrome):** откройте ссылку → меню ⋮ → «Добавить на главный экран» или «Установить приложение».

## Контрагенты

- **Даня** — вкладки «Аренда помещения» (Коммуналка, Аренда), «Аренда ДТФ», «Счета», «Деньги в долг», «Выплачено» и временная «Требует сортировки»
- **Максюшка** — вкладки «Аренда помещения» (Коммуналка, Аренда), «Счета», «Деньги в долг», «Выплачено» и «Требует сортировки». Без «Аренда ДТФ»
- Новые контрагенты создаются с вкладками «Деньги в долг», «Выплачено» и «Требует сортировки»

## Возможности

- На главной: сумма долгов нам, прибыль по процентам, сумма наших долгов и потери на процентах
- Карточку контрагента можно удалить с главной и из профиля
- Выдали в долг — со сроком возврата; взяли в долг — срок можно не указывать
- Карточки Дани: аренда вместе с коммуналкой, отдельно Аренда ДТФ и «Всего отдано»
- Итоги в карточке: дебет, кредит, сальдо, прибыль за всё время (зелёный сальдо — нам должны, красный — должны мы)
- Аналитика за весь период, за год или за месяц
- Над списком записей у любого контрагента и любой вкладки: добавить запись, поиск и сворачивание. Поиск смотрит все записи контрагента, не только текущую вкладку
- Выплата не отдельная запись: она привязана к долгу. В рабочих вкладках остаются только открытые долги с остатком
- Погашенные записи уходят во вкладку «Выплачено» у контрагента; там их можно открыть и при необходимости поправить
- Внести оплату можно из самой записи («Оплата» или внутри долга) либо через «Добавить запись» → тип «Возврат» с выбором долга
- Временная вкладка «Требует сортировки»: выплаты без выбранного долга. Карандаш меняет сумму, дату и способ оплаты, «К долгу» привязывает выплату. Когда разнесёте всё — вкладку уберём
- Счёт с тем же номером, той же датой и тем же юрлицом повторно не создаётся — откройте уже существующую запись
- При добавлении и правке счёта нужно выбрать юрлицо: ООО «МАКСИЛАЙТ» или ИП Баляева К.М.
- Если выплата больше остатка по выбранному долгу, долг закрывается на эту сумму, а разница появляется во вкладке «Требует сортировки» — её можно привязать к другому долгу
- Если выплату сняли с долга (не туда привязали), она не пропадает: возвращается во вкладку «Требует сортировки». Окончательно удалить её можно только оттуда
- Способ оплаты у выплаты: наличные, перевод, на счёт юрлица, безналичный расчёт, услугами, товарами, взаимозачёт
- Выдача в долг с обязательным сроком возврата; если к этой дате нет полного погашения, контрагент подсвечивается красным
- Необязательный комментарий у любой записи
- Фильтр таблицы по способу оплаты
- Авторасчёт прибыли по займам
- Автосохранение на устройстве и синхронизация через Supabase между устройствами

## Синхронизация между устройствами

Проект: [https://sqsnhapkgtdjjkiexfrn.supabase.co](https://sqsnhapkgtdjjkiexfrn.supabase.co)

Клиент Supabase подключается с адресом проекта и publishable-ключом. Приложение остаётся одним HTML-файлом, без `npm` и без React: библиотека подключается из браузера.

Один раз создайте таблицу — в SQL Editor вставьте скрипт из «Настройки синхронизации» или выполните:

```bash
supabase login
supabase init
supabase link --project-ref sqsnhapkgtdjjkiexfrn
supabase db push
```

После этого записи с телефона и компьютера сохраняются в облаке и подтягиваются на других устройствах.
